NoteDay é uma aplicação web moderna de agenda e organização diária, desenvolvida para ajudar o usuário a planejar compromissos, acompanhar tarefas e visualizar sua produtividade de maneira simples e elegante.

Inspirada na experiência de um caderno digital, a aplicação possui uma interface minimalista, responsiva e intuitiva, com foco em clareza, organização e rapidez de uso. O usuário pode adicionar tarefas com data, horário e observações, iniciar uma atividade, registrar automaticamente seu tempo de execução, finalizá-la, marcá-la como concluída ou excluí-la.

As tarefas são organizadas visualmente por status: pendentes, em andamento e concluídas. A aplicação também exibe a duração de cada atividade, um resumo diário de produtividade e navegação entre diferentes datas.

O projeto foi desenvolvido com React e TailwindCSS, utilizando armazenamento local do navegador (localStorage) para preservar tarefas e preferências de tema sem necessidade de cadastro ou banco de dados. Também conta com modo escuro, layout adaptado para desktop e dispositivos móveis, cards elegantes, sombras suaves e elementos visuais discretos. By Guilherme Fontes @fontesideias
